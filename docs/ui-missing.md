# 화면에 필요한데 없는 것

> 2026-11-20 밤, 배포된 사이트(CloudFront, main `48297ea` 기준)를 로그인한 상태로 화면마다 확인했다.
> 흐름 기준은 `docs/user-flow.md`. 데스크톱 폭에서만 봤고, 모바일 폭·면접 진행·리포트·사용자 메뉴는 확인하지 못했다.

## 1. 화면 요소

| # | 화면 | 없는 것 | 이유 | 우선순위 |
| --- | --- | --- | --- | --- |
| 1 | 공고 상세 | **"지원하러 가기" 주 버튼** | 원문 링크가 아래 "출처" 안에 작은 글씨로만 있다. 오른쪽 적합도 카드에 외부 링크 버튼으로 올린다 | 높음 |
| 2 | 공고 상세 | **저장(북마크) 버튼** | 목록에서는 저장되는데 상세에서는 안 된다 | 높음 |
| 3 | 공고 상세 | **적합도 카드 고정(sticky)** | 스크롤하면 카드가 같이 올라가 "이 공고로 모의면접" 버튼이 사라지고 오른쪽이 빈다 | 중간 |
| 4 | 홈 | **추천 기준 표시** (예: "부산 · 금융·보험 · 전문대 졸업 예정 기준 [수정]") | 추천이 무엇을 보고 나왔는지 알 수 없다. 지금은 공고 목록 오른쪽 끝의 작은 "프로필 수정" 링크뿐이다 | 중간 |
| 5 | 정책 목록 | **필터 칩**(신청 가능 / 확인 필요 / 지난 회차)과 **건수·기준일 줄** | 같은 화면의 공고 탭에는 있어서 두 탭 구성이 다르다 | 중간 |
| 6 | 공고 목록 | **더 보기 또는 페이지 이동** | 20건에서 끝나고, 더 있는지 알 수 없다 | 낮음 |
| 7 | 홈 AI 멘토 | **대화 기록** | 새로 고치면 대화가 사라진다. 최근 질문 몇 개만 남겨도 "이어서 하기" 역할을 대신한다 | 낮음 |
