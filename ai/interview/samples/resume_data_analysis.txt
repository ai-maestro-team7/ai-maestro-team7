[프로젝트] 공공데이터 활용 부산 관광 수요 분석 프로젝트
3학년 2학기 전공 프로젝트에서 네 명이 한 팀이 되어 부산 관광 수요를 분석했습니다. 저는 데이터 수집과 전처리를 맡았습니다. 공공데이터 포털의 관광지 입장객 통계와 기상 자료를 Python으로 내려받고, 서로 다른 날짜 형식과 누락 값을 정리해 하나의 테이블로 합쳤습니다. 처음에는 관광지 이름이 자료마다 달라 합치기 어려웠는데, 이름 대응표를 직접 만들어 해결했습니다. 정리한 데이터로 요일과 강수 여부에 따른 방문객 차이를 SQL로 집계하고, 결과를 데이터 시각화 도구로 대시보드로 만들어 발표했습니다. 비 오는 주말에 실내 관광지 방문이 늘어난다는 점을 근거와 함께 보여 줬다는 평가를 받았습니다.

[인턴] B기관 데이터팀 체험형 인턴
여름방학에 B기관에서 민원 접수 데이터를 엑셀에서 SQL 테이블로 옮기는 일을 도왔습니다. 담당자가 매주 손으로 하던 집계 작업을 Python 스크립트로 바꿔 반복 작업을 줄였습니다.
